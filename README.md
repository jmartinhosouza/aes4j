## AES for Java

This repository contains an algorithm (`Aes4j.java`) that implements the Advanced Encryption Standard in Java without the aid of external libraries. It was my solution (with help from [@FelipeBona](https://github.com/FelipeBona)) for a college assignment for which I received a perfect grade.
I was so happy with the result that I decided to store it here on GitLab.

For reference, the `AesCipher.java` file contains the equivalent solution using the `javax.crypto.Cipher` library.
